# How to assign filter?

> 分类：Solution home / Light / Luminaires ｜ 更新：Thu, 15 Apr, 2021 at  3:01 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000066350-how-to-assign-filter-

It is possible to use filters in evo. These can be imported from the installed filter catalogue. A new resulting spectrum can be generated from the spectrum of the lamp and the filter in this way.
