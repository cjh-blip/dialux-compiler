# Hardware requirements

Here are our recommendations:

A modern Intel or AMD processor works perfectly with our DIALux evo software. Multiple cores (4-8) will definitely help to reduce the calculation time.
The CPU (clock frequency and number of cores/threads: 4/8 @ 4 GHz vs. 6/12 @ 4 GHz) is probably the most important factor for the calculation. If possible, the calculation uses all available threads. Desktop systems naturally have an advantage here. With notebooks there is always the possibility that the system throttles down the CPU during longer full load to avoid overheating. 

The RAM is very important. It should be at least 4 GB, 8-16 GB is recommended for professional use.

The graphics card must support at least OpenGL 3.2. For the performance (the calculation) the graphics card hardly plays a role. The calculation runs completely on the CPU, so the GPU has no influence on it. The GPU is "only" important for the visualization/display of the CAD, i.e. working in CAD is much smoother for complex projects with many surfaces and large textures when using a modern graphics card with a lot of VRAM (1 GB at least, 2 GB or more are recommended). For "normal" projects even the GPU cores in modern Intel/AMD CPUs are good enough. A lot of VRAM brings advantages, because there is less risk of running out of texture memory in very complex projects. This is especially relevant for large projects and very high resolutions (4K+).

The minimum requirement for the display resolution is FullHD (1,920 x 1,080).

Our DIALux evo software runs under the following Windows operating systems:
- Windows 10 (64 bit)

- Windows 11 (64 bit)

Systems with ARM CPU are currently not supported!

We recommend a modern 64-bit operating system. A fast SSD hard disk and a good, quiet cooling system are also an advantage.
