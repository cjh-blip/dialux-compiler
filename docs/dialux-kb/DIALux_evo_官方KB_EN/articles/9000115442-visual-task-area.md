# Visual task areas

> 分类：Solution home / Calculation / Calculation objects ｜ 更新：Wed, 26 May, 2021 at  1:56 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000115442-visual-task-area

With this tool you can define the visual task area according to DIN EN 12464-1 in which the actual visual task is performed. Draw it rectangularly or polygonally in your CAD window. The surrounding area and the background area required by the standard are generated automatically, but can be edited and adjusted later. DIALux evo calculates the maintenance values of illuminance and uniformities on specified illuminance grids for you. You can view the results calculated on these areas in the results overview and in the documentation.
