# Actions in "Furniture and Objects" tool

> 分类：Solution home / Construction / Furniture and Objects ｜ 更新：Fri, 10 Feb, 2023 at  2:34 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000123946-actions-in-furniture-and-objects-tool

In this tool you have the possibility to draw furniture and objects in different arrangements. We would like to briefly explain all the arrangements and functions in this tool below:

Draw rectangular arrangement
With this function you can insert all furniture and objects in a line arrangement.

Here, first of all, you need to choose whether you want to place by quantity or by distance of objects/furniture. Depending on which placement type you have chosen, you can make further settings.

If you have chosen "Placement by quantity" of objects/furniture, you can both determine the number of objects for the two axes and choose from various alignment options.

If you have chosen "Placement by distance" of the objects/furniture, you can determine object distances for both axes as well as choose from different dimensioning and alignment options. 

You also have the option to lock/unlock individual grid lines and add/remove additional grid lines. These options are available when you right-click on a grid line.

Draw polygonal arrangement
With this function you can insert all furniture and objects in a polygonal arrangement. 

Otherwise, the same selections and options are available here as when drawing a rectangular arrangement.

Draw circular arrangement
With this function you can insert all furniture and objects in a circular arrangement. 

Here you then have the option of selecting various settings for the arrangement, such as the radius, the circumference and the start and end angles.

Draw line arrangement
With this function you can insert all furniture and objects in a line arrangement.

Here you must first choose whether you want to place by quantity or by distance of objects/furniture. Depending on which placement type you have chosen, you can make further settings.

If you have chosen "Placement by quantity" of objects/furniture, you can both determine the number of objects and choose from various alignment options.

If you have chosen "Placement by distance" of objects/furniture, you can determine object distances as well as choose from different dimensioning and alignment options.

With start and end point of the line arrangement you determine the position.

Once the line layout is drawn, you can still manually change the position and rotation of the line layout.

Place individual object
With this function you can insert a single object into your project, which you have currently selected.

Here you then have the option to set the position, rotation and size of the object.

Draw extrusion body
With this function you have the possibility to draw an extrusion body.

An extrusion body is a three-dimensional body whose base surface is first drawn with a two-dimensional tool and to which a depth is assigned after creation.

After creation, you then have the option to adjust the position, rotation and size of the extrusion body afterwards.

Automatic arrangements for spaces
With this function you have the possibility to have the respective selected object or piece of furniture automatically inserted for an space. Our evo software then decides what the optimum number and spacing of the object is for this space.

You then have the same tools available as after drawing a rectangular arrangement to make subsequent corrections to the arrangement.

Replace selected objects / Replace all objects of this type
This function allows you to exchange several objects at once.

For example, if you have placed an office chair in all your rooms in a project, you can easily replace this office chair with another chair using the "Replace all objects of this type" function.

If you only want to replace these chairs in one specific room, select the chairs and use the "Replace selected objects" function.

Object catalog
As in DIALux 4, DIALux evo has some standard objects as well as an object catalog that can be started in the "Furniture and objects tool" of the construction mode.

Either by dragging and dropping directly into the project, or by clicking on "Apply", your own objects/furniture can be added to the DIALux evo database.

By right-clicking on an object, you can add it to your favorites.

The objects you used in the project are listed at the top of the list. In addition, the number of the respective objects occurring in the project is also displayed.

Starting with our evo version 11, the user also has the option of saving his self-constructed furniture or other objects in DIALux.
