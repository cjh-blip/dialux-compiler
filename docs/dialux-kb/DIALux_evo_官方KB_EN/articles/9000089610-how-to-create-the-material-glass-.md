# How to create the material "glass"?

> 分类：Solution home / Construction / Materials ｜ 更新：Thu, 16 Feb, 2023 at 12:03 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000089610-how-to-create-the-material-glass-

To create the "Glass" material, the "Transparent" material type must be selected. A desired transmittance can then be set for this type. In the image below, the settings for our window glass can be seen.

Alternatively, a window can be placed in a room. Here the glass material can be selected with the pipette function "Pick material".
