Site

This view shows you the entire project, the site, including all buildings and objects.
You can change the designation of the site, the appropriate utilisation profile, maintenance factors and the site orientation here.

Building

Focuses the selected view on the selected building.
If you have more than one building, you can select the desired building via the drop-down menu.
As soon as you have drawn more than one building, the menu is displayed.
They are numbered according to the order in which they were drawn.

Storey

Focuses the selected view on the selected storey.
If you have drawn more than one storey, you can select the desired storey using the drop-down menu.
As soon as you have drawn more than one storey, the menu is displayed.
They are numbered according to the order in which they were drawn.

Room

Focuses the selected view on the selected room.
If there are several rooms, you can select the desired room via the drop-down menu.
The menu is displayed as soon as you have drawn more than one room.
They are numbered according to the order in which they were drawn.

Display plans 

With this function you can either load plans into the project or display or hide already imported plans.

3D Rendering

Here you can display your project in 3D.
You can also edit objects in this view if you are in the corresponding tool.
This means that to change the building contour, for example, you must be in the storey and building construction tool.

Floorplan view

The floor plan view shows you the top view of the object you have selected (e.g. room 1).

Front view, Side view from the right, View from behind, Side view from the left

These views are hidden by default and can be switched on if required.

Zoom to entire scene

Zooms in or out of the selected view so that all objects are displayed full screen.

Tape measure

With the help of the tape measure you can measure in the drawing at any time and have the measurement displayed.

Set coordinate system

With this function you can set a new coordinate system in your project.
