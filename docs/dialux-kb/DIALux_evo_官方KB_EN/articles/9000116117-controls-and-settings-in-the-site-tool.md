# Controls and settings in site tool

> 分类：Solution home / Construction / Site ｜ 更新：Fri, 25 Mar, 2022 at  9:37 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000116117-controls-and-settings-in-the-site-tool

Active site
Here you can give the "Active site" a different name and add a description.

Properties
In the properties, you can select a usage profile and define the traffic flow.
Under details, data such as maintenance values and usage times can be changed.

Maintenance
In the Maintenance section, you can either select the maintenance interval and the pollution category according to the standard CIE 97:2005 standard or enter a flat-rate, fixed maintenance factor.

Site alignment
Here you can edit the exact position of the site (longitude & latitude) with north orientation and edit the time zone.
