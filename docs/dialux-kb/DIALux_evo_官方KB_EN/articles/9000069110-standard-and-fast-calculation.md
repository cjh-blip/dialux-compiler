# Is it possible to calculate only separate rooms?

> 分类：Solution home / Calculation / Calculation time ｜ 更新：Fri, 11 Jun, 2021 at  9:23 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000069110-standard-and-fast-calculation

In the calculation settings you can determine whether the entire project should be calculated or only a single storey/ room. If you want to calculate the entire project, you must always select the "Standard" method. In the "Fast" mode, only the part of the building whose view is currently selected is calculated. You can therefore use this to calculate individual rooms or light scenes. The fast method only gives you an insight into the calculation results in the corresponding room.
