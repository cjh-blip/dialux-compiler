# Actions in site tool

Draw new building
Before drawing a new building, you can preset both the number of floors and the total building height.

Draw floor elements
With this function you can draw rectangular, circular and polygonal floor elements.

Draw north arrow
With the North Arrow you can easily mark the northern cardinal direction in your drawing, which you define with only 2 points, where the 2nd point you set should point to the north.
You can also edit the orientation of the arrow in the "Site Alignment" control.

Duplicate building
This function allows you to duplicate a completed building by selecting it.
You decide which objects are copied to the duplicate.
By deselecting the checkbox, you remove the objects that you do not want to be automatically transferred.
