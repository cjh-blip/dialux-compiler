# Add a view to the documenation

> 分类：Solution home / Documentation / Settings ｜ 更新：Fri, 23 Feb, 2018 at  9:50 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000089775-add-a-view-to-the-documenation

A view can created at "Export -> Views -> Save new view". You can also use the Hotkey "Strg + 0-9" and "ALT + 0-9" to select it again. 

A camera position is saved which can selected every time again. All changes which are done in the project will be also updated in the view. 

To add a view to the documentation, e.g. to the project cover, views or room summary, you have to select page configuration at the top of the CAD view. The desired views can then be added or removed by using the corresponding buttons.
