# Actions in building apertures (Doors/Windows/Skylight)

> 分类：Solution home / Construction / Apertures ｜ 更新：Mon, 25 Apr, 2022 at  1:52 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000123931-actions-of-the-apertures-windows-doors-skylights-

Position active aperture
Use the action "Position active aperture" to insert the aperture at the mouse position with the dimensions you have set under properties.
Draw new aperture
With the function "Draw new aperture" you determine the width of the aperture yourself by defining "Start" and "End" of the aperture with mouse clicks.

Adjust building opening for the wall thickness
With this function you adapt the depth of the door to a changed wall thickness. This way you do not have to replace the door with a new door first, but adapt the door already in use to your project.

Replace selected apertures
This function allows you to replace a aperture in one step.
Select the aperture to be replaced and then select "Replace selected apertures". 

A window will open in which you can select the new aperture.
After selecting the new aperture, it will automatically be inserted into your building.

Replace all apertures of this type
With this function you have the possibility to exchange all apertures of one type in one step.
Select the aperture type to be replaced and then select "Replace all apertures of this type". 

A window will open in which you can select the new aperture type.
After selecting the new type, they are automatically inserted in your building.

Load daylighting system file
With this function you have the possibility to import a daylight control system file of the formats .ODLS or .DDLS for a aperture.

Properties of doors/windows/skylights
Here you can change the standard dimensions of the selected aperture.
Various other settings, such as mullion position and mullion width, can be changed for the different window types.
