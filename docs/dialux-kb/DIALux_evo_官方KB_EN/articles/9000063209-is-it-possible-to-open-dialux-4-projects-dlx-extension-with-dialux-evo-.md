# Is it possible to open DIALux 4 projects (.DLX extension) with DIALux evo?

> 分类：Solution home / Import / Export / Import ｜ 更新：Wed, 22 Oct, 2025 at 11:10 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000063209-is-it-possible-to-open-dialux-4-projects-dlx-extension-with-dialux-evo-

At the moment, only interior projects created with our DIALux 4 software from version 4.12 onwards can be imported into DIALux evo.

This is not yet possible for outdoor scenes.

To do this, please open the import process in evo via “File -> Import -> DX4 indoors”:
