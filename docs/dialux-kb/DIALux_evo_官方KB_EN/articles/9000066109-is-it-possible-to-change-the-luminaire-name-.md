# Is it possible to change the luminaire name?

> 分类：Solution home / Light / Luminaires ｜ 更新：Thu, 15 Apr, 2021 at  1:32 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000066109-is-it-possible-to-change-the-luminaire-name-

The name of luminaires cannot be changed in the documentation. However, it is possible to edit the luminaire name in the project tree with a double-click.
