# Is evo downward compatible?

> 分类：Solution home / Opening & Saving of evo files / Project file ｜ 更新：Wed, 7 Apr, 2021 at 10:04 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000073614-is-it-possible-to-load-projects-created-in-the-latest-evo-version-with-an-older-evo-version-

DIALux evo is not downward compatible. This means that project files created in an older version can be read in by a newer version. The reverse is not possible. This has several reasons, such as the integration of certain new functions that cannot be interpreted by an older version because the functions were not yet available.
