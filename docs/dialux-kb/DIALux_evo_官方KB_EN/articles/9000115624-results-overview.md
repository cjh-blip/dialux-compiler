# Result tool

> 分类：Solution home / Calculation / Results ｜ 更新：Mon, 14 Jun, 2021 at 11:51 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000115624-results-overview

With the result tool, you can check the determined values after the calculation. You can get an overview of the results with the help of a traffic light system, switch individual calculation surfaces on and off, select surfaces for documentation and show isolines, false colours and value charts on individual surfaces.

Open results overview

You will find the results overview on the right above the CAD window. You can show and hide it with a single click. You can open the results overview in any mode and check the values at any time.

Result filter
The results overview automatically shows all calculation surfaces that are available in the respective CAD view. This means, for example, that you see all calculation surfaces of a room if a single room is visible in the CAD and all calculation surfaces of a storey if the storey view is selected.
For larger projects, there can be a lot of calculation surfaces. Therefore, you can show and hide each surface separately in the CAD with the eye icon. A selection in the results overview automatically shows or hides the corresponding surface in the CAD, regardless of the currently selected view status.

Isolines, false colours and value chart
You can show or hide isolines, false colours or value charts for each selected surface, regardless of whether it is a virtual calculation surface or a real surface in the room. Select the surface and press the desired action. Calculation surfaces are automatically listed in the results overview. You can select real room surfaces directly in CAD with the action "Results on surface". The surfaces selected in this way are also available in the documentation.

For surfaces with more than one result type, e.g. illuminance and luminance, you must decide which of the two results you want to display graphically by selecting the corresponding result type. With the action "Delete diagrams" you switch off the display again.

Traffic light system

With large projects, it is difficult to get an overview of the calculated results. The traffic light system helps here. On most calculation objects you will find a small symbol in the colours red or green. It quickly shows you which of the calculation objects have fulfilled their specified target value and which have not. You set the target values in the profiles in the spaces tool. Calculation surfaces without a specified target value do not receive a traffic light symbol. If necessary, the traffic light can also be deactivated. To do this, deselect the item "Show evaluation" under "Settings".
If you need more information about a result, you can use the small arrows in the results overview to show details about the respective calculation surface and the results.
