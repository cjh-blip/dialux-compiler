# Where can I find the general color rendering index Ra?

> 分类：Solution home / Documentation / General ｜ 更新：Mon, 9 May, 2016 at 11:42 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000069085-where-can-i-find-the-general-color-rendering-index-ra-

The output of this value in the evo documentation is only possible with luminaires, which are imported from plugins of lighting manufacturers in our DIALux evo software and where the value has been deposited.

In the data sheets of the luminaires you can find the color rendering index Ra.
