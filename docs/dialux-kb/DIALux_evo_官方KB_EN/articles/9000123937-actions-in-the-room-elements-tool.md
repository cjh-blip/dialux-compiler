# Actions in room elements tool

> 分类：Solution home / Construction / Room elements ｜ 更新：Tue, 26 Apr, 2022 at  9:32 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000123937-actions-in-the-room-elements-tool

There are different ways to draw a room element:
- Draw rectangular room element

- Draw circular room element

- Draw polygonal room element

Not every option for drawing a room element is available for every type of room element. 
You can freely position and rotate each room element via the "Positioning".
In addition, the current clearance height is displayed for each room.

In the following, we will briefly discuss the various prefabricated room elements:

Beam
The beam is inserted into the room at the ceiling in the form of a cuboid with the standard dimensions 1x1x1 metre and can then be changed as desired.
With the beam, you only have the option of drawing a rectangular room element.

Column (rectangular)
The rectangular column is automatically adjusted to the room height when it is inserted. You can then change the dimensions as you wish.
With the rectangular column you have the option of drawing a rectangular and polygonal room element.

Column (round)
The round column consists of at least 5 segments. The more segments the column has, the "rounder" it looks. You can then change the dimensions as you wish. The round column is also adjusted to the room height when it is inserted.
With the round column, you only have the option of drawing a round room element.

Platform
After inserting a platform, you can change the width, length and height.
With the platform you have the option of drawing a rectangular, circular and polygonal room element.

Ramp
After inserting a ramp, you can change the width, length and height, which results in the slope.
You can also enter the slope directly, which results in the height of the room element.
With the ramp, you only have the option of drawing a rectangular room element.
