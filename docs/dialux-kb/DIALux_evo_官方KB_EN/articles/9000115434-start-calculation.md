# Start calculation

> 分类：Solution home / Calculation / Start calculation ｜ 更新：Fri, 17 Feb, 2023 at 11:32 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000115434-start-calculation

The calculation button becomes active as soon as Evo detects that a calculation is possible under the following conditions:

- a luminaire has been inserted into the project or
- in the light scene tool the sky type is not set to "No daylight" and a window is present.

During the calculation, the button changes from "Calculate all light scenes" to "Cancel calculation".

With the second button you can discard the results.

If the current results were discarded by another action, the constellation occurs that both buttons are active.
