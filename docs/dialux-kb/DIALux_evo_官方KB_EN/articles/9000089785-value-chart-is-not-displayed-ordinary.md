# Value chart is not displayed ordinary

> 分类：Solution home / Documentation / Settings ｜ 更新：Wed, 31 Aug, 2016 at 11:25 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000089785-value-chart-is-not-displayed-ordinary

Sometimes it can happen that there are so many values in the value chart that it is not possible to display all of them. This can happen for example for very large working planes. 

In this case it is advisable to reduce the amount of values (Value chart settings -> Quantity).
