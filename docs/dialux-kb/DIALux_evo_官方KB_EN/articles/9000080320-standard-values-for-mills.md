The standard values for service illuminance (Em [Lux]), color appearance (F), color rendering group (Ra), and unified glare restriction class (UGRL) according to EN 12464-1 are listed in the table for the various types of interior or activity. The ratings for service illuminance, color rendering group, and direct glare restriction class represent minimum values to be met by the lighting system.
