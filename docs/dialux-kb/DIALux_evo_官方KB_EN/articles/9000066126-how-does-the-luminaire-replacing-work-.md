# How does the luminaire replacing work?

> 分类：Solution home / Light / Luminaires ｜ 更新：Thu, 15 Apr, 2021 at  2:02 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000066126-how-does-the-luminaire-replacing-work-

You can replace luminaires with alternative products using the "Replace selected luminaires" or "Replace all luminaires of this type" function. To do this, select the corresponding luminaire(s) in the CAD view and then select the new luminaire type in your luminaire list.

Afterwards, the changes must be confirmed via the "Apply" button.
