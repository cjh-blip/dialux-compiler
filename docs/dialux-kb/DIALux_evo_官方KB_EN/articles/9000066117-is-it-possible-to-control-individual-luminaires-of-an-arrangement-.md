# Is it possible to control individual luminaires of an arrangement?

> 分类：Solution home / Light / Light scenes ｜ 更新：Thu, 22 Apr, 2021 at 11:58 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000066117-is-it-possible-to-control-individual-luminaires-of-an-arrangement-

If you have added a luminaire arrangement, you can of course control each luminaire individually. To do this, you only have to create a new light scene and create a separate luminaire group for each individual luminaire. With the first mouse click, the entire arrangement is selected. With a second mouse click, individual luminaires can be selected.
