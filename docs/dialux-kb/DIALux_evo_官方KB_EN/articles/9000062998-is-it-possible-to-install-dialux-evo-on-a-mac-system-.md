# Is it possible to install DIALux evo on a Mac system?

> 分类：Solution home / Installation evo / Miscellaneous ｜ 更新：Fri, 15 Mar, 2024 at  9:52 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000062998-is-it-possible-to-install-dialux-evo-on-a-mac-system-

Our DIALux evo lighting design software has only been developed for Windows x86-64 systems, which we also support exclusively. We have no plans for a native Mac version in the near future.
 
However, we can give you successfully tested workarounds with which it is possible to use DIALux evo on an Apple system. 
 
It is possible to use DIALux evo with the virtualization software VMware Fusion in any Windows environment supported by DIALux evo on a Mac system with an x86-64 CPU.
 
You can use DIALux evo with Parallels Desktop in any Windows environment supported by DIALux evo on a Mac system with an x86-64 or Apple silicon (ARM) CPU (M1, M2, …).
