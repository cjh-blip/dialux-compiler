# Why is a building created for each room after the STF import?

> 分类：Solution home / Import / Export / Import ｜ 更新：Wed, 7 Apr, 2021 at 11:10 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000111192-why-is-a-building-created-for-each-room-after-the-stf-import-

If rooms are intersected in the STF, they cannot be imported into a storey. Therefore, they are each imported into a separate building.
If no rooms intersect in the STF, all rooms are imported into one storey.
