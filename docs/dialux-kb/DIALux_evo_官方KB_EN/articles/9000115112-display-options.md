# Display options

> 分类：Solution home / Construction / User Views ｜ 更新：Thu, 27 May, 2021 at 12:42 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000115112-display-options

In DIALux evo there is the possibility to change various display options by clicking on the "screen icon" in the upper right area.

01) Show/hide coordinate system
A green, a blue and a red auxiliary line are shown. The red line corresponds to the X-axis, the green to the Y-axis and the blue to the Z-axis of the coordinate system. At the intersection of the three lines is the origin of the local coordinate system.
Each view, i.e. terrain, building, floor and room, has its own coordinate system.

02) Display north arrow
With this function the north arrow can be shown or hidden.

03) Show/hide reference/help lines
With the tool "Help lines and labelling" different reference objects can be created. These have no influence on the calculation and are used for orientation or as a construction aid. With the option "Show/hide reference/help lines" these can be hidden together, so that they do not disturb for example in screenshots or views for the output.

04) Always show contours of manually created areas
Contours of manually created areas can be permanently shown or hidden here.

05) Show/hide working planes
Each room initially has a working plane. This can be shown or hidden with this option.

06) Show/hide calculation surfaces/points
Calculation surfaces and points are used to determine lighting parameters. They can be shown and hidden with this option.

07) Wireframe view
Surfaces of buildings and objects are usually displayed with their material color or illuminated. For complicated objects, it can be helpful to hide the filled surfaces so that the surface edges are displayed as lines in CAD.

08) Show/hide graphic results
Results on individual surfaces can be visualized with the help of the Results tool. There they can also be shown and hidden per surface. With this option, all surface results are shown and hidden together. 

09) Show/hide light distribution curves
This option fades in and out the light intensity distribution for selected luminaires and luminaire groups. It is also possible to select several luminaires at the same time.

10) Show/hide LEO alignment
This option shows/hides the LEO alignment for selected luminaires and luminaire groups. Several luminaires can be selected at the same time.

11) Show/hide room designations
DIALux evo automatically generates a room name for each created room. This can be edited by the user in the area tool. 
In addition, the text tool can be used to write notes and comments directly into the CAD. Under certain circumstances, these may interfere with screenshots or views, so they can be shown or hidden using this option.

12) Show/hide sky texture
DIALux evo creates an artificial horizon that is used in CAD for better orientation. For uncalculated projects it is a blue day sky, for calculated projects it is a black night sky. With this option the sky texture can be faded in and out.

13) Show/hide false colours
With the help of this option the calculated light textures are displayed in false colors. The colors used can be set at the bottom of the screen.

14) Show/hide light textures
The light textures of calculated projects can be shown/hidden at this point. 
Attention: After a calculation, the light textures are not automatically switched on again. If you do not see any light textures after a calculation, check the set view options.

15) Show light visualisation
This option allows you to visualize the lighting effect of a single selected luminaire directly in CAD, even if the project has not yet been calculated. This is a very useful function, especially when aligning luminaires.

16) Display energy consumption
This option displays the current energy consumption of the scene at the bottom of the CAD window. Further setting options can be found in the "Energy Consumption" tool.
