# Why is it not possible to start a PlugIn evo?

> 分类：Solution home / Light / DIALux PlugIns ｜ 更新：Thu, 22 Apr, 2021 at  3:20 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000074069-why-is-it-no-longer-possible-to-start-a-plugin-

Registy cleaner can delete important information on the computer system. After running such a cleaner, the problem may occur that luminaire catalogues are no longer displayed or the luminaire transfer to DIALux no longer works. 
In this case, the luminaire plugin or DIALux must be reinstalled.
