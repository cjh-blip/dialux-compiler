# Norms

> 分类：Solution home / Settings / General settings ｜ 更新：Mon, 20 Feb, 2023 at 11:40 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000115052-norms

Open the "Standards" mode via the menu File -> Settings -> Standards. Here you can make individual settings related to the topic of standards.

Default settings
Here you can choose between different settings. With the button "Create copy of the selected template" you create a new template which you can edit. The templates provided by DIALux evo cannot be edited.
You can make the following settings:
- Uniformity
- Spacing-to-height ratio (SHR, needed for Rug calculation)
- Maintenance value according to CIE 97:2005 or fixed

Profiles

In the profiles we have compiled general specifications, recommendations and guidelines for individual spaces. DIALux uses these values when selecting a profile in the spaces or in a room. You can create or change your own profiles by clicking on "Create copy of the selected profile". The profiles supplied by DIALux cannot be changed.
