# Which file formats are supported for importing plan files?

> 分类：Solution home / Construction / Drawings/DWG import ｜ 更新：Fri, 28 May, 2021 at  9:41 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000116105-which-file-formats-are-supported-for-importing-plan-files-

We offer you the import of the following plan file formats:

- IFC files
- DWG files
- DXF files
- JPG files
- JPEG files
- PNG files
- BMP files
- TIF files
- TIFF files
- GIF files
