# How can the target value of the illuminance be deactivated in the room summary?

> 分类：Solution home / Documentation / Settings ｜ 更新：Tue, 27 Dec, 2016 at 11:48 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000106835-how-can-the-target-value-of-the-illuminance-be-deactivated-in-the-room-summary-

To hide the target value in the room summary, simply deactivate the checkbox for the "Target values" in the page settings of the documentation. Please note that you must then click on the refresh button to update the output page.
