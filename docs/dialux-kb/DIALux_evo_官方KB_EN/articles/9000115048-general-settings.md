# General settings

> 分类：Solution home / Settings / General settings ｜ 更新：Fri, 17 Feb, 2023 at  2:30 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000115048-general-settings

Open the "Settings" mode via the menu File -> Settings -> General settings.

Common
Here you can set how often DIALux evo should remind you to save your project and the maximum number of work steps that can be undone. Furthermore, you can activate the search for evo updates here. 

After installation, DIALux evo runs in the language of your operating system. Under language settings you can change the language of the user interface and the printout, as well as switch between the metric and imperial length system. It is also possible here to display photometric units in the European system or also in the imperial system.

Project
You can adjust programme settings as well as default settings for objects here. If new objects are created in the planning, they behave according to their default settings.

At this point you can activate simple street planning for projects as well as combine the EIR/SR calculation for roadways.
The default reflection factors of rooms for ceilings, walls and floors can also be set.
In addition, default settings can be defined here for working planes (separately for interior and exterior).

- Choice between DIALux standard (norm) or self-defined values
- Default value for height
- Default value for wall zone
- Selection between evaluate overall uniformity or not

Storage locations
Here you can specify the location for your project folders, under which your projects are saved by default.

Furniture, materials and layouts are also stored on your hard disk. You can specify the respective storage location here.

CAD
Here you can specify how many decimal places should be displayed on dimension lines. 
In addition, you have the option of activating the automatic creation of isolux lines and value graphics after the calculation. 

Default settings for texts and diagrams

- Default colour and size for room names (room stamps)
- Default colour and size for text objects
- Default colour and standard size for value charts
- Default colour and size for isolux lines

Calculation 
General result settings can be made here.

Internet
In principle, this should work for almost all users in the standard setting (system setting).
If this should not be the case, the user has the option of switching to a direct connection "No proxy" (if one exists or is possible) or setting the proxy parameters (proxy and port) manually. 
If the proxy server used requires authentication, the user name and password can be entered in the login data. Clicking on the login data opens the Windows login mask.
If there are still problems logging in, the timeout value can be increased.

Keyboard
Here you will find a list of the available keyboard combinations (overview only, no customization possible!).
