Menu "File":

Via the menu [File] you have the possibility - as in other familiar Windows applications - to start new projects, to load projects, to close existing projects and to save projects. 

In addition, you can use various import interfaces: 

We offer here the import of various plan file formats (.jpg / .jpeg / .png / .bmp / .tif / .tiff / .gif / .dwg / .dxf / .ifc ).

It is also possible to import STF files and DIALux 4 indoor projects. 

Luminaire files of common formats (.uld / .ldt / .ies / .cib / .ltl), can also be imported into our evo software.

In addition, it is possible to import daylight system files (.odls / .ddls), furniture files (.m3d / .3ds / .sat), image files (.jpg / .jpeg / .png / .bmp / .tif / .tiff / .gif) and layout files (.mrt) into our evo software.

Please note that you cannot import DIALux 4 indoor projects in an installed 64-bit evo version. This feature is currently only available in the 32-bit evo application (please also read the following article of our DIALux evo knowledge base "Is it possible to open DIALux 4 projects (.DLX extension) with DIALux evo?").

Furthermore, you have the possibility to open the print preview and the print function via this menu item.

The general settings and the standards control center can be accessed via the "Settings" subitem.

You also have the option of opening the most recently opened projects and closing our DIALux evo software.

Menu "Edit":

The [Edit] menu supports you during your planning with standard commands to undo or redo one or more actions. 

Of course, you can also cut, copy, paste or delete various objects (furniture, luminaires). 

The menu also contains an entry for clearing the selection.

Menu "Insert":

If you select luminaires or objects in the [Insert] menu, you will automatically be directed to the corresponding tool. However, this function is only available if you have already started planning.

Menu "View":

The [View] menu first allows the zoom setting for the project and switching to full screen mode.

In addition, opening new tabs in another view bar directly above the CAD window can be done in this menu. This procedure is especially helpful if you have to switch between many different views. Of course, you can also use this to close individual or all tabs. 

If the CAD view is not completely visible, you can display the entire scene by calling up the "Zoom to entire scene" menu item. 

You can also access the "Documentation" mode in the Views menu.

Menu "?":

The [?] menu hides helpful information with direct forwarding to the respective pages. 

Here you will find fast and reliable support for your planning. You can reach the DIAL homepage, the knowledge base, the newsletter registration and the user forum in this menu. 

You will also find direct links to our accounts on YouTube, Youku, Facebook and Twitter.

It is also possible to start the search for new evo updates in this menu.

The installed version number can be found in the bottom menu item [Info about DIALux evo].
