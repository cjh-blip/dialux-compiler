# How to change a spectrum?

> 分类：Solution home / Light / Luminaires ｜ 更新：Thu, 15 Apr, 2021 at  2:46 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000066342-how-to-change-the-spectrum-

In order to change the lamp spectrum, first select the corresponding luminaire in the lamp tool. Then click on the "Change" button in the "Colourimetric data" control. Afterwards, a new spectrum can be selected from a list of predefined spectra.

Since the format for .IES and .LDT files does not contain any information for the spectrum, it makes sense to correct the spectrum manually, especially for these photometry files.
