# How to remove objects in a project?

> 分类：Solution home / Construction / Furniture and Objects ｜ 更新：Tue, 14 Feb, 2023 at  1:48 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000089808-how-to-remove-objects-in-a-project-

Objects can be selected directly and removed from the project via the context menu (right mouse button) or the "Delete" key.

Sometimes it is not so easy to find or select an object in large projects. In this case it can sometimes be easier to search for the object in the project overview (project tree). Objects can also be selected here and then removed from the project.
