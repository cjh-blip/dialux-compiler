# Where can I find the Boolean operations (unite, subtract, intersection)?

> 分类：Solution home / Construction / Furniture and Objects ｜ 更新：Tue, 14 Feb, 2023 at  1:37 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000072827-where-can-i-find-the-boolean-operations-unite-subtract-intersection-

The Boolean operations are displayed as soon as you have marked more than one object and are in the option "Construction -> Copy and arrange".

However, it is not possible to select "furniture and objects" together with room elements. Furthermore, the Boolean operations cannot be applied to two room elements.
