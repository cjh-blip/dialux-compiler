# How could I install DIALux evo?

> 分类：Solution home / Installation evo / Miscellaneous ｜ 更新：Thu, 2 Jul, 2020 at 11:41 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000114897-how-do-i-install-dialux-evo-

Start the "Setup.exe" file and follow the instructions of the installation program. 
To improve the software, some information is sent to DIAL during the setup: 

- A unique ID that cannot be traced back to you. 

- Information about the installed operating system (version, service pack, ...). 

- Hardware information (RAM, screen resolution, ...).

- Detailed information about the capabilities of your graphics adapter.

No personal data is transmitted.
