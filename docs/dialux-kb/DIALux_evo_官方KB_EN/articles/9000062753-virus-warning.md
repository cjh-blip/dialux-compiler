# Virus warning

> 分类：Solution home / Installation evo / Virus warning ｜ 更新：Thu, 2 Jul, 2020 at 11:31 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000062753-virus-warning

Before each release of our DIALux evo software, we make sure that our evo setup is virus-free and can be installed without risk.

Shortly after the release, however, it happens sometimes that anti-virus programs react to our setup with a false positive, simply because these programs do not yet know our setup.

There has not yet been a single case where this message has proven to be correct.
