# Luminaire groups vs. Control groups

Luminaire groups
Luminaire groups are used to define which luminaires are switched (dimmed) together in a light scene. Each luminaire can only be in one luminaire group in a light scene. Luminaire groups can be managed in the light scene tool.
You can find more information in our YouTube tutorial "Luminaire groups for lighting scenes": YouTube tutorial

Control groups

Control groups cannot be created manually and no names can be assigned to control groups. The control groups correspond to the necessary wiring to be able to realise all created light scenes. Luminaires in a control group are therefore switched together (regardless of the light scene). The control groups are recalculated by evo if necessary (e.g. if another light scene is created).
A luminaire group in a light scene can internally consist of several control groups. However, the dimming values must only be set once for the entire luminaire group.
