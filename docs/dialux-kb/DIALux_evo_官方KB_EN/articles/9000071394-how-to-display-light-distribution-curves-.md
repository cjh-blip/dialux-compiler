# How can I display the light distribution curves (LDC's) of luminaires?

> 分类：Solution home / Light / Luminaires ｜ 更新：Fri, 16 Apr, 2021 at  9:21 AM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000071394-how-to-display-light-distribution-curves-

The display of the light distribution curves (LDC) can be switched on in the display options.
As soon as the LDC icon is activated in the display options, only the corresponding luminaires have to be selected in the CAD view. The yellow light distribution curve is then automatically displayed. 
The display of LDCs can be activated for a single luminaire as well as for all selected luminaires.
