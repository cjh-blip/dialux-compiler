# Tipps to decrease calculation time

> 分类：Solution home / Calculation / Calculation time ｜ 更新：Thu, 10 Jun, 2021 at  2:14 PM
> 来源：https://evo.support-en.dial.de/support/solutions/articles/9000066366-tips-for-faster-calculation-time

An oversized floor element has a negative influence on the calculation performance. Due to this, the floor element in the site view should only be dimensioned as large as necessary.

Furthermore, a building that is very far away from the origin (position 0/0/0) can also have a significant negative impact on the calculation time.

If the luminaire groups of a light scene are combined with the same dimming values, this can have a positive effect on the calculation time.
