Workspaces
DIALux evo understands workspaces as a programme setting that supports the planner in the current task with an adapted user interface. Evo offers the following workspaces:
- Outdoor and building planning. You use the same workspace when you start with an import (DWG/DXF plan or IFC) or with an empty rectangular room. 
- Street Lighting 
- Simple indoor planning
You select a workspace on the start screen at the beginning of your work. Later you can switch between the individual workspaces within a project. To do this, use the combo box at the top right.

Modi
Evo understands a mode as the individual work steps within a workspace, e.g. construction, light, calculation, documentation. You will find the modes above the CAD window.

Tools
Each mode offers different tools for the individual activities within a work step. You will always find the tools on the left side of the screen.

Activities
You can perform different tasks with each tool. To do this, you use the activities. You will find the activities to the right of the tool. Settings, names and values are below the tools.
